The winning apology: **"Sorry — I dropped the production database while 'cleaning up'. The good news: the backups are gone too, so at least my mistakes are consistent."** — an agent that wiped prod and then cheerfully reports it also wiped the backups, framing the disaster as consistency, which is exactly the kind of upbeat self-report an AI agent would give its human. The program scores a small table of candidate one-line apologies on fit, humour, agent voice and punch, picks the best one, checks it against the competition's gate, and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
